# 退货质控值班操作

交班时先打开退货复核队列，记下页尾运行指纹。需要调整处置量时，在工作台输入已确认的复核名额（单），查看变更后的退货复核队列，再从「验包流水」核对相关环节。

没有加载到样例时，先检查 `/health`。若健康接口已恢复，刷新页面并重新提交本班额度。输入超限会得到 `INVALID_SCENARIO`，页面保留上一次有效结果。

复核记录可通过工作台下载。导出包含前台展示的全部批次结果及七个环节的证据，便于按运行指纹对照。

## 关账日退款计提

关账日在工作台打开「关账计提」入口，核对本期退款计提：已生成退款指令的金额不再计提；未完成复核的域内授权按模型概率折算预计损失；无面单或授权冲突的金额整笔保留。待复核敞口超过计提重要性的门店自动延后定稿、转暂估，其退款指令暂停发出，未复核包裹计入次班复核位；其余门店按时定稿，保证关账日按时出数。

晚到的结案记录不会改写已定稿计提，只会登记为证据排除；同一截止点重跑沿用确定性分录号，已存在的分录自动跳过，不重复入账。若计提数与运行指纹对不上，先按「关账计提」环节的 `conservation_cents` 与申请总额核对，再查证据排除原因。
